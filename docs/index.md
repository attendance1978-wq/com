# com

com is a small programming language written in base 1: every number is a tally
of `1`s. The implementation is plain C11 with no dependencies.

- [Getting started](getting-started.md) - build, run, commands
- [Syntax](syntax.md) - the language reference
- [Grammar](grammar.ebnf) - formal grammar
- Standard library: [core](stdlib/core.md), [io](stdlib/io.md), [math](stdlib/math.md)
- Examples: [hello](examples/hello.com), [fibonacci](examples/fibonacci.com), [binary](examples/binary.com)
